# hw2 國立金門大學校務資訊系統專案
## 資工四 111210529 陳宏傑
我設計了國立金門大學之校務資訊系統介面。透過導入現代化的網頁設計風格（以米色系為主視覺），並採用單頁式應用程式 (SPA) 架構，改善傳統頁面跳轉的延遲感，大幅提升系統操作之流暢度與使用者體驗。

## 系統核心功能

### 一、 系統登入與身分驗證機制
本系統實作了完整的三層式畫面架構（登入頁面、主系統介面、登出機制）。使用者需輸入學號（如：111210529）與密碼方可進入系統。執行登出操作後，系統將自動清除使用者輸入資料並安全跳轉回登入首頁。

### 二、 動態選課與課表連動系統 (核心重點)
提供互動式選課介面，使用者可於清單中執行「加選」與「退選」操作。系統會透過狀態管理自動攔截選課結果，並即時同步至「我的課表」頁面。課表畫面採用標準之星期一至星期日、每日八節課之網格排版，選定之課程會自動填入對應節次，並具備自動計算當前總學分數之功能。

### 三、 線上請假與證明文件上傳
實作線上假單申請介面，支援本機端圖片檔案上傳（如就醫證明、事假證明等），並透過 FileReader 介面提供即時預覽功能。若需更換附件，使用者可點擊移除按鈕清空當前檔案並重新上傳。

### 四、 歷年學期成績查詢
建置學期成績查詢模組，透過下拉式選單設計，支援查詢自 112 學年度第一學期至 115 學年度第一學期之歷年成績範圍。

## 開發技術棧

* 前端架構：HTML5, CSS3, 原生 JavaScript (DOM 操作與狀態管理)
* 後端架構：Node.js, Express (負責靜態檔案路由與伺服器架設)
